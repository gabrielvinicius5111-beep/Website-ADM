ADM SITE V4.2 — PUBLICAÇÃO CLOUDFLARE PAGES

IMPORTANTE:
- A chave CPFHub NÃO fica no app.js.
- Cadastre a chave no Cloudflare como Secret com o nome: CPFHUB_API_KEY
- A pasta /functions precisa permanecer na raiz do projeto.

Estrutura:
index.html
app.js
catalogo.js
styles.css
quote.js
refinements.css
functions/
  api/
    consultar-cpf.js

Para publicar com Functions, use um repositório Git conectado ao Cloudflare Pages
ou Wrangler. O upload direto do painel não suporta Pages Functions.

Depois de criar/conectar o projeto:
Cloudflare Dashboard > Workers & Pages > seu projeto >
Settings > Variables and Secrets > Add
Nome: CPFHUB_API_KEY
Valor: sua NOVA API key
Marque/Salve como Secret/Encrypt.

Faça um novo deploy depois de cadastrar o Secret.

Rota criada:
GET /api/consultar-cpf?cpf=00000000000

O navegador recebe somente:
{"success":true,"name":"Nome da Pessoa"}

A Function não devolve nascimento ou gênero.
